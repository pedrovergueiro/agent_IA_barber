# Agente IA para Barbearia

Um agente de IA conversacional que desenvolvi pra automatizar o atendimento de uma barbearia — responde perguntas sobre serviços, preços e horários disponíveis.

Foi meu primeiro projeto mais sério com agentes de IA. Aprendi bastante sobre como estruturar um fluxo de conversa, manter contexto entre mensagens e integrar com APIs externas.

## O que aprendi
- Como criar agentes conversacionais com IA
- Gestão de contexto em conversas de múltiplos turnos
- Deploy e variáveis de ambiente em projetos JavaScript
- Como documentar um projeto de forma útil

## Stack
JavaScript · Node.js
